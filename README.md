# SwiftRev Portfolio

This project is a Vite + React frontend for the SwiftRev website.

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

## Notes

- Static assets used by the app live in `public/`.
- The current app runs as a public frontend and no longer depends on the old hosted-builder Vite/auth setup.
- Some page images are still served from existing remote media URLs and can be localized later if you want the project to be fully self-hosted.
